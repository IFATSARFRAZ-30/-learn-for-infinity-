What is an AI agent, really?

Not just a chatbot. Watch both work on the same job. · 4 min read · interactive

A chatbot talks. An agent does.

Give both this job: "Find the cheapest Friday bus from Faisalabad to Lahore and put it in my calendar." Press the buttons and watch.

The agent loop

observe→think→act→check

An agent repeats this loop: look at the situation, decide the next step, use a tool (search, calendar, spreadsheet), check the result, and go again until the goal is done. The model supplies the thinking. The tools give it hands.

Agents can make mistakes, so important actions like payments usually need a human to approve first.
